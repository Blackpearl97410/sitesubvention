# Upload Turso V1

Fichier a uploader dans Turso :

`dossier-studio-client-v1.sqlite`

Ce fichier contient :

- le schema de base V1 ;
- un client de demonstration ;
- un dossier de demonstration ;
- des documents et activites de demonstration ;
- aucun token d'acces client actif.

Apres l'upload dans Turso, il faudra ajouter un token d'acces hashé dans la table `client_access_tokens`.
